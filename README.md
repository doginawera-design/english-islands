# English Islands

Учебный сайт английского языка: словарь, произношение и интерактивные задания.

## Запуск

Статический сайт без установки зависимостей и сборки:

```bash
python3 -m http.server 8000 --directory dist
```

Откройте http://localhost:8000.

HTML, CSS, JavaScript, изображения и учебные материалы находятся в `dist/`. Для статического хостинга используйте эту папку.

Импортировано из Sites. Автоматическая синхронизация с Sites не настроена.
